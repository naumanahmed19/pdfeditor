# Microsoft Edge Add-ons listing

## Product name

PickPDF — PDF Reader & Editor

## Short description

Read, edit, organize, fill, sign, and export PDFs locally in your browser.

## Full description

PickPDF turns a browser tab into a complete PDF workspace. Open documents from your computer, read and search every page, make changes, and save an edited copy without uploading the file to a PDF website.

Use PickPDF to:

- edit existing text, add text boxes, images, highlights, drawings, shapes, comments, and redactions;
- fill PDF forms, create reusable signatures, and design new form fields;
- reorder, rotate, duplicate, insert, extract, merge, split, and compress pages;
- add watermarks and page numbers;
- make scanned documents searchable with local OCR;
- work with several documents in tabs or a split view; and
- ask the optional AI assistant to summarize, explain, or answer questions about a document.

PickPDF is local-first. PDF reading and editing happen on your device, with no account required. Documents and session data are stored in your browser so you can resume your work. OCR processing runs locally after its language data is downloaded.

The built-in Gemma model can run on your device after its model files are downloaded. If you configure an external AI provider, document context is sent only when you choose to include it, and that provider's terms and privacy policy apply.

All executable extension code is packaged with PickPDF. The extension does not load or execute remotely hosted JavaScript.

## Single purpose

PickPDF lets users read, edit, organize, fill, sign, and export PDF documents from a browser tab.

## Permissions explanation

The extension does not request optional browser permissions. Its toolbar button opens the packaged PickPDF workspace in a new tab.

## Remote code declaration

No. All executable JavaScript and WebAssembly are included in the extension package. PickPDF may download OCR language data and optional AI model weights, but these are data files, not remotely hosted executable code.
